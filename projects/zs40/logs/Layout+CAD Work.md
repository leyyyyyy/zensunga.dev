# Layout + CAD Work
**2026-06-27**

Using the website <a href = "https://www.keyboard-layout-editor.com">keyboard-layout-editor.com</a>, I was able to make a preview layout of what I wanted the keyboard to look like. With such a small constrained space, the keyboard will make use of 3 additional layers to retain full functionality. 

<br>
Since I was making everything from scratch, I thought I might as well make it cooler by making a split keyboard. This design would also increase it's portability as it can fit into smaller sized bags. 

<br>
<br>
The concept for the split keyboard would be that one side is hand-wired and the other side uses a custom pcb, both with custom firmware. The back would be visible so as to showcase the inner workings.
